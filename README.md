# Vite Plus TanStack Start 

Vite Plus for TanStack Start Development with AI Agents.

## Usage

First, we need to install Vite Plus globally.

```bash
curl -fsSL https://vite.plus | bash
```

### Setup

Setup the project by installing dependencies, and bootstrapping environment files.

```bash
vp run setup
```

### Build

Build the project in production mode.

```bash
vp run build
```

### Test

Run the project tests.

```bash
vp test
```

### Type Check, Lint & Format

Analyze the code to find problems with `typescript`, `oxlint` and `oxfmt`.

```bash
vp check
```

Automatically fix problems.

```bash
vp check --fix
```
